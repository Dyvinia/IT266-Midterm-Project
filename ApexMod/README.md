This mod adds various things from Apex Legends.

# Installation
Copy the `ApexMod` folder to your Quake 4 directory and then run the shortcut.

# Features

## Legends
### Octane - [oct | octane]  
Passive: Healing  
Tactical [Q]: Stim  
Ultimate [Z]: Jump Pad

### Revenant - [rev | revenant]  
Passive: Stalker  
Tactical [Q]: Pounce  
Ultimate [Z]: Forged Shadows

### Valkyrie - [valk | valkyrie]  
Passive: Jetpack  
Tactical [Q]: Missile Swarm  
Ultimate [Z]: Flight Core

## Movement
Sprinting [Shift]  
Pressing Shift while walking forwards allows you to sprint

Sliding [Ctrl]  
Pressing Crouch while sprinting lets you slide

Grenade Throw [G]  
Pressing G will throw a grenade (5 second cooldown)

## Evo Armor
Doing damage will level up your armor (you start off at level 0). When you are at full health, your armor passively regenerates slowly.
- Level 0 - 0 Armor
- Level 1 - 50 Armor
- Level 2 - 75 Armor
- Level 3 - 100 Armor

# Added Controls
- `P`: Help
- `Shift`: Sprint
- `G`: Grenade
- `Q`: Tactical Ability
- `Z`: Ultimate Ability

# Added Commands
- `oct` or `octane`: Changes current legend to Octane
- `rev` or `revenant`: Changes current legend to Revenant
- `valk` or `valkyrie`: Changes current legend to Valkyrie
- `evoup`: Levels up evo armor
- `grenade`: Throws grenade
- `tactical`: Tactical ability
- `ultimate`: Ultimate ability
- `apexhelp`: Help screen
